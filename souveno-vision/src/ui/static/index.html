Privacy & security position

  • Anonymous by default. People are tracked as temporary, camera-local IDs such as Person 12. IDs reset when a source restarts and are never linked across cameras.
  • No facial recognition, no employee names. This version does not implement or store biometric templates.
  • On-premise processing. Video never leaves the machine; only structured events can optionally be posted to a webhook you configure.
  • Credentials. RTSP usernames and passwords are held in memory only, masked in all logs and never written to the database. Use a read-only camera/NVR account.
  • Evidence. Snapshots and short clips are stored locally with configurable retention and cleanup. Restrict folder access to authorised operators.
  • Audit trail. Every acknowledgement, resolution or dismissal is recorded with actor, note and time.
  • Before production: role-based access control, privacy notice and employee-policy review, restricted access to snapshots/clips, retention policy sign-off.

About this demonstration

Souveno Vision Intelligence is an intelligence layer for existing CCTV infrastructure: the camera provides video; Souveno converts it into operational events, alerts, evidence and management insights.

Scope. This is a single/few-stream proof of concept to validate use cases before hardware sizing. It does not process 348 cameras simultaneously; the pilot benchmarks real streams first.

Integration. Production input may be RTSP, ONVIF discovery, the NVR/VMS API or a manufacturer SDK — not every camera supports RTSP.

Licensing. The proof-of-concept detector (Ultralytics YOLO11) is AGPL-3.0; a commercial licence or a differently licensed model is required before client deployment — see LICENSING.md.
